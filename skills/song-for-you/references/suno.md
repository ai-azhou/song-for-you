# 粘贴稿怎么出、下一步怎么告诉用户

你只出提示词，歌由用户在自己选的工具里生成。Suno 和海绵音乐的选项名称、有没有某个选项、费用，都以用户界面为准；他说的和这里对不上时照实说，不猜。这里不写价格，也不给帮助页链接。

## 出粘贴稿

跑 `scripts/to_suno.py`。粘贴稿的说明文字用用户的语言，一首歌一组，叫「第 1 首」「第 2 首」，不用内部说法。海绵音乐的两段（中文风格描述、完整歌词）直接写在聊天里。

## Suno 字段对照（Custom 模式，每首粘一次）

| Suno 里的栏 | 从写歌说明的哪里来 | 说明 |
|---|---|---|
| Title | `title` | 不填的话平台可能自己起名 |
| Lyrics | `song.lyrics` | 原样，标签和提示一个字不改 |
| Styles | `style.tags` | |
| Exclude | `style.exclude` | 在高级选项里 |
| 人声 | `style.vocal` | `female`、`male` 选对应性别；`mixed`、`duet`、`group` 写在 Styles 里，界面没有对应选项就不选 |

## 告诉用户下一步

交付时用几句白话说完，不教具体按钮：

- **Suno**：切到 Custom 模式，按粘贴稿把各段粘进对应的框，Exclude 在高级选项里；有改写风格词的选项（Variety）就关掉，其余先用默认。
- **海绵音乐**：风格描述和歌词分别粘进对应的框。
- **多出几版**：同样的输入每次结果不同，先多生成几版看方向。
- **怎么听**：先查有没有漏唱、唱错字、奇怪的声音，再挑最想再听的一版（`listening.md` 第一节）。
- **回来时说具体**：哪一段、哪一句、哪方面不对，你来改提示词，给新的粘贴内容。
- **工具里的操作**：能不能只重做一段、续写、裁剪，以他用的工具界面为准。
